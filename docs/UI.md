# filesync — 界面设计

> 2026-09-22：界面范围已扩展为中心 Web（Vue 3）+ 节点桌面（Tauri 2 + Vue 3），保留 Ratatui TUI。
> 图形界面的运行方式、已实现功能和限制见 [GUI.md](GUI.md)。下列终端原型仍是 TUI 的后续目标，不代表全部已实现。

## 1. 技术选择

一个 Rust 可执行文件，TUI 与 `filesync agent` 分进程。界面通过本机控制 API 操作后台，不直接读写数据库。TUI 内存与后台 agent 的 20 MB 限制分开统计。

## 2. 分层：UI 只是客户端

```
        ┌────────────────────────────┐
        │          filesync agent             │  ← 所有业务逻辑
        │        (daemon)            │     扫描 / 拉取 / 待定队列 / 传输 / 配置
        └─────────────┬──────────────┘
                      │ 本地 socket 上的 JSON API（与 UI 形态无关）
        ┌─────────────┼─────────────┬──────────────┐
        ▼             ▼             ▼              ▼
       TUI           CLI        (预留)         (预留)
                                桌面 GUI      本地 Web 面板
```

两条铁律：

1. **UI 不持有业务状态**，只持有视图状态（当前页、光标位置、输入框内容）。
   所有真实状态从 daemon 拉、或由 daemon 推。
2. **UI 不直接读写 `state.db`**，一切通过 IPC。所以 `state.db` 永远只有 `filesync agent` 一个写者。

## 3. IPC 协议

当前基础版传输使用带 Bearer 认证的回环 HTTP API，动态端口保存在数据目录 `control.addr`。下面的 op 表为完整目标契约，尚未全部实现。

### 3.1 请求 / 响应

```json
→ {"id":1,"op":"pending.list"}
← {"id":1,"ok":true,"data":{"items":[
     {"upstream":"node-A","rel_path":"报价单/2026-Q1.pdf","size":2202009,
      "mtime":1749717720,"target":null}
   ]}}
```

### 3.2 事件推送（无 `id` 就是事件）

```json
← {"event":"pending.added","data":{"upstream":"node-A","rel_path":"报价单/2026-Q3.pdf"}}
← {"event":"transfer.progress","data":{"rel_path":"设计/mockup-v3.fig","done":27300000,"total":46137344,"bps":1258291}}
← {"event":"sync.done","data":{"share":"node-A","files":12,"bytes":4404019,"ms":8102}}
← {"event":"relation.changed","data":{"upstream":["node-A"],"downstream":[]}}
```

### 3.3 操作清单

| op | 说明 |
|---|---|
| `status.get` | 仪表盘数据（职责、上下游、待定数、上次同步） |
| `relation.list` | 我的上下游（从中心拉到的） |
| `pending.list` | 待定队列 |
| `pending.claim` | 单文件认领 `{upstream, rel_path, target}` |
| `pending.claimBatch` | 批量认领 `{upstream, prefix, dst_root}` |
| `pending.ignore` | 忽略 |
| `source.list` / `source.add` / `source.remove` | 发布方配置 |
| `transfer.list` / `pause` / `resume` / `retry` | 传输控制 |
| `config.show` / `config.export` / `config.reload` | 配置查看与固化 |
| `log.tail` | 日志 |

**设计要点**：CLI 的 `--json` 用的是同一套 op，所以脚本和 TUI 走完全相同的路径，
不存在"只有 TUI 能做"的操作。

## 4. 界面原型

### 4.1 仪表盘（启动页）

```

│                                                                     │

│  我的下游    —                                                      │
│  当前职责    订阅方                                                  │
│                                                                     │
│  ╭ 待定 3 个 ────────────╮  ╭ 活跃传输 1 ───────────────────────╮  │
│  │  按 p 查看并认领        │  │ 报价单/2026-Q2.pdf                │  │
│  ╰────────────────────────╯  │ ████████░░░░░░░ 62%  1.1/1.8 MB   │  │

 [p]待定 [t]传输 [s]发布 [r]关系 [c]配置 [l]日志 [?]帮助 [q]退出
```

### 4.2 待定队列 ★ 核心界面

```
╭─ 待定文件 (3) ──────────────────────────────────────────────────────╮
│                                                                     │
│    上游路径                   大小     修改时间    目标位置           │
│  ▸ 报价单/2026-Q1.pdf        2.1 MB   06-12 10:22  —（未认领）       │
│    报价单/2026-Q2.pdf        1.8 MB   06-13 09:01  —（未认领）       │
│    设计/mockup-v3.fig         44 MB   06-13 15:40  —                 │
│                                                                     │
│  已选 1/3                                                           │

 [space]选择 [m]指定目标 [M]批量认领 [i]忽略 [s]跳过 [a]全选 [enter]详情
```

待定项的目标为空。命中有效前缀映射的文件自动同步，不再进入待定。

### 4.3 认领目标目录（按 `m` 或 `M` 后）

```
╭─ 选择目标目录 ──────────────────────────────────────────────────────╮
│  为 2 个文件指定落盘目录（文件名沿用上游）                            │
│                                                                     │
│  ╭ 当前位置 ───────────────╮  ╭ 预览 ──────────────────────────╮   │
│  │  ..                      │  │ ~/work/报价单/                 │   │
│  │  Documents/              │  │   2026-Q1.pdf                  │   │
│  │▸ work/                   │  │   2026-Q2.pdf                  │   │
│  │  Pictures/               │  │                                │   │
│  │  Downloads/              │  │                                │   │
│  ╰──────────────────────────╯  ╰────────────────────────────────╯   │
│                                                                     │
│  ~/work/报价单/                                          [Tab]补全   │
╰─────────────────────────────────────────────────────────────────────╯
 [↑↓]移动 [enter]进入 [space]选定此目录 [n]新建目录 [esc]取消
```

**关键交互设计：只需选一个目录，文件名沿用上游。** 一次认领不用打任何字。

## 5. 当前实现与后续工作

- 已实现：连接本机 agent，前 100 条待定/冲突/错误列表，按键选择，`m` 单文件认领、`M` 父目录前缀认领，`q` 只退出界面。
- 当前认领使用绝对路径文本输入；目录选择器、发布多选、完整分页与来源展示待实现。
- 后续新增项必须保持选中行身份和滚动锚点，不能仅依靠排序保证稳定。
- 系统通知、中文/英文切换、超管 TUI、分发状态矩阵待实现。
- 中心 Web 和节点桌面是本期新增交付范围，桌面通过相同的本机控制 API 调用后台。
